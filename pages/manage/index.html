SCP:SL 查询管理

从 scplist.kr 找服务器

输入名称关键词（例如 沈阳）搜索在线服务器，点「填入」会把 ID 填到下面的表单。A2S 在你的服务器上连不通时，用 scplist ID 最稳。

    添加 / 更新服务器

    服务器按群隔离。群标识写 平台:群号，只写群号时默认 aiocqhttp:。同群同名再次保存会更新 IP 和端口。

    或者用 A2S（UDP，需要服务器能连通）：

    管理员

    管理员全局共用，可使用 /bind /unbind /bindlist /op。格式 平台:用户ID，只写 QQ 号时默认 aiocqhttp:。在这里添加不受“首位管理员”限制。

      随机语录

      每次 /cx 出图时随机抽一条显示在标题下方。共 0 条（上限 5000，单条 ≤ 200 字）。

      从文件导入

      支持 .txt（一行一条）、.md（自动去掉标题行和列表符号）、.csv（按行）、.json（字符串数组，或 {"quotes": [...]}、对象里的 text/quote/content 字段）。UTF-8 或 GBK 编码均可，重复的会自动跳过，超过 200 字的行会被忽略。导入是追加；想覆盖请先「清空全部」。
