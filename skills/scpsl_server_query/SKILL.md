# SCP:SL 服务器查询插件使用说明

> 本 Skill 只提供**说明**。真正执行查询、绑定和权限检查的是插件命令，权限由插件代码强制校验。
> 本插件**没有**注册 LLM 工具（function tool），AI 不能主动调用查询；请让用户自己发送命令。

## 命令与权限

- 所有命令**仅限群聊**，私聊中不可用。
- 服务器绑定**按群隔离**，每个群只看到和管理自己绑定的服务器。
- 管理员**全局共用**，在任一群成为管理员后，所有群都有效。

| 命令 | 谁可用 | 作用 |
|---|---|---|
| `/cx` | 群内所有人 | 实时查询本群已绑定服务器的在线人数 |
| `/bind 服务器名 scplist服务器ID` | 管理员 | 用 scplist.kr 的 ID 绑定（推荐，不依赖 UDP） |
| `/bind 服务器名 IP 端口` | 管理员 | 用 A2S 绑定或更新服务器（名称不含空格，端口 1–65535） |
| `/mcbind 服务器名 地址[:端口]` | 管理员 | 绑定 Minecraft Java 服务器 |
| `/mc` / `/mc 地址[:端口]` | 群内所有人 | 查询本群绑定的 MC 服务器 / 临时查询一台，含服务端版本 |
| `/bindlist` | 管理员 | 查看全部已绑定服务器 |
| `/unbind 服务器名` | 管理员 | 解除绑定 |
| `/op` | 仅在尚无管理员时 | 第一个执行者成为首位管理员 |
| `/op 用户ID` | 管理员 | 添加管理员（ID 须真实，可写 `平台:ID`） |

## 出图与管理页

- `/cx` 默认以本地渲染的图片返回（失败自动退回文字）。
- 服务器、管理员、背景图、随机背景都可在 WebUI 插件页「SCP:SL 查询管理」里管理。

## 示例

```
/bind 一号服 192.0.2.10 7777
/cx
/unbind 一号服
```

## 查询失败排查

1. 「连接超时」：A2S 使用 UDP，确认防火墙/安全组放行该 UDP 端口。
2. A2S 查询端口不一定等于游戏端口，请以服务器配置或服务商为准。
3. 「域名解析失败」：检查域名拼写，或改用 IP。
4. 「无效响应」：该端口可能不是 A2S 端口。
5. 详细原因只记录在 AstrBot 日志中，普通用户看不到。
