# astrbot_plugin_scpsl_a2s

通过 A2S 协议实时查询多个 SCP:SL 服务器在线人数的 AstrBot 插件。Python ≥ 3.10。

**v1.3.0 新增：Minecraft Java 版服务器查询（含服务端版本）**
- `/mcbind 服务器名 地址[:端口]`（管理员）：绑定本群的 MC 服务器，端口省略默认 25565，并会尝试解析 SRV 记录（装了 `dnspython` 才会生效，没装就直接连）。解除绑定用 `/unbind 服务器名`，`/bindlist` 会标注 `MC`。
- `/mc`：查询本群已绑定的 MC 服务器；`/mc 地址[:端口]`：临时查询任意一台（所有人可用，每人 5 秒冷却）。
- 结果（图片或文字）包含：在线人数 / 上限、**服务端版本**（即服务器上报的版本名，例如 `Paper 1.20.4`、`Velocity 1.7.2-1.20.4`）、延迟；文字模式额外显示协议里的版本信息。`/cx` 也会把 MC 服务器和 SCP:SL 服务器一起显示。
- 走 **TCP**（Server List Ping），不需要 UDP。仅支持 1.7 及以上的 Java 版；**基岩版（UDP）与 1.6 以前的旧协议不支持**。
- 安全：默认禁止查询内网/回环/保留地址（防止被群友拿来探测机器人所在内网）。
- WebUI「服务器」页的表单新增「类型」下拉，选 Minecraft Java 版即可添加、测试（测试会显示版本）。

**v1.2.0 新增：scplist.kr 数据源**
A2S 是 UDP 查询，很多环境下会「连接超时」。现在可以直接用 scplist.kr 的服务器 ID 绑定，人数从 scplist 官方前端 API（`api.scplist.kr`）读取，不需要服务器能连通 UDP。
- 群内：`/bind 服务器名 scplist服务器ID`（例如 `/bind 沈二 12345`）；原来的 `/bind 服务器名 IP 端口`（A2S）仍然可用，两种可以混用。
- WebUI「服务器」页新增「从 scplist.kr 找服务器」：输入名称关键词（如“沈阳”）搜索在线服务器，点「填入」即可拿到 ID。
- scplist 有限流（列表/详情 10 次/分钟，players 20 次/分钟）。插件只请求 `api.scplist.kr`，并对 players 结果缓存 10 秒、列表缓存 60 秒，所以 10 秒内重复 `/cx` 不会重新请求。
- scplist 的 players 接口会省略离线服务器，这类服务器在图里显示「离线」。
- ⚠️ scplist 文档没有写明返回 JSON 的字段名，解析做了宽松兼容（`id/serverId`、`players/currentPlayers`、`maxPlayers/max` 等多种写法）。如果 `/cx` 提示「返回格式无法识别」，请把 `https://api.scplist.kr/api/v2/servers/players?serverIds=ID` 的返回内容反馈出来再适配。

**v1.1.0 新增**
- `/cx` 结果由 **Pillow 在本地渲染成一张图片**（毛玻璃卡片 + 背景图），不依赖 AstrBot 的网络文转图服务，也不需要浏览器。渲染失败会自动退回文字。
- 插件自带 **WebUI 管理页**（AstrBot 侧边栏/插件详情页里的「SCP:SL 查询管理」）：管理各群已配置的服务器、管理员权限、背景图、是否随机背景。
- 需要 AstrBot ≥ 4.24（Plugin Pages 功能）才有管理页；更旧版本命令与出图照常可用，只是没有管理页。

## 命令与权限

**所有命令仅限群聊使用，私聊中不可用。**（WebUI 管理页不受此限制，由 Dashboard 登录保护。） 服务器绑定**按群隔离**（每个群有自己的服务器列表，互不相通）；管理员名单**全局共用**（在任意群成为管理员后，在其他群同样是管理员）。

| 命令 | 普通用户 | 管理员 |
|---|---|---|
| `/cx` | ✅ | ✅ |
| `/op` | 仅管理员列表为空时可初始化 | ✅ |
| `/op 用户ID` | ❌ | ✅ |
| `/bind 服务器名 IP 端口` | ❌ | ✅ |
| `/bindlist` | ❌ | ✅ |
| `/unbind 服务器名` | ❌ | ✅ |

权限由插件代码强制校验，使用插件自己的 `admins.json`，与聊天平台管理员无关。管理员身份以 `平台名:用户ID` 保存，不同平台的相同 ID 互不影响。

## 1.0. 安装

## 1.1.0 解压安装

## 1.1.1. 下载与解压
```bash
unzip astrbot_plugin_scpsl_a2s.zip
```

## 1.1.2. 安装到插件目录
将整个 `astrbot_plugin_scpsl_a2s` 文件夹放入 AstrBot 的 `data/plugins/`：
```bash
cp -r astrbot_plugin_scpsl_a2s /path/to/AstrBot/data/plugins/
```

## 1.1.3. 安装依赖
AstrBot ≥ 4.5.0 会根据 `requirements.txt` 自动安装。若未自动安装，在 AstrBot 所用的 Python 环境中手动执行：
```bash
pip install -r data/plugins/astrbot_plugin_scpsl_a2s/requirements.txt
```
Docker 部署请进入容器后执行。

## 1.1.4. 启用 / 重载
WebUI → 插件管理 → 找到「SCP:SL 服务器人数查询」→ 管理 → 重载插件（首次安装可重启 AstrBot）。

## 1.1.5. 检查 Skill 是否被识别
插件自带 `skills/scpsl-server-query/SKILL.md`。在 WebUI 的 Skills（技能）管理页查看是否出现 `scpsl-server-query`。Skill 只是说明文档，本插件**没有**注册 LLM 工具，AI 不会主动查询服务器。

## 1.2.0 通过Astrbot插件管理器安装

## 1.2.1 WebUI → 插件管理 → 安装插件 → 直接上传此插件压缩包

## 1.2.2. 检查 Skill 是否被识别
插件自带 `skills/scpsl-server-query/SKILL.md`。在 WebUI 的 Skills（技能）管理页查看是否出现 `scpsl-server-query`。Skill 只是说明文档，本插件**没有**注册 LLM 工具，AI 不会主动查询服务器。

## 2.0. 管理员命令

## 2.1. 初始化首位管理员
管理员列表为空时，**第一个**发送 `/op` 的用户成为管理员。请在部署后立刻在群里自己执行（私聊不可用，所以请选一个只有可信成员的群，避免被别人抢先）。

## 2.2. 添加其他管理员
```
/op 123456789          # 默认与你同平台
/op telegram:987654321 # 指定平台
```
必须使用真实用户 ID。

## 2.3. 绑定多个服务器
```
/bind 一号服 192.0.2.10 7777
/bind 二号服 scpsl.example.net 7778
```
同名再次绑定会更新 IP 和端口。绑定只对**当前群**生效，换一个群需要重新绑定。名称不能含空格。

## 2.4. 查询在线人数
群内任何人发送 `/cx`，每次都会重新查询**本群**绑定的所有服务器，不使用缓存。

## 2.5. 查看与解除
```
/bindlist
/unbind 一号服
```

## 3.0. 管理文档

## 3.2. 排查 A2S 查询失败
- A2S 走 **UDP**，防火墙/安全组需放行对应 UDP 端口，且 AstrBot 所在机器能出站访问。
- **A2S 查询端口不一定等于游戏连接端口**，请以服务器配置或服务商说明为准；填错端口会超时。
- 「连接超时」：端口、防火墙或服务器未开启查询。
- 「域名解析失败」：检查域名或改用 IP。
- 「无效响应」：该端口不是 A2S 端口。
- 详细异常只写入 AstrBot 日志，不展示给用户。

## 3.1. 备份
数据文件为 `servers.json`（按「平台:群号」分组保存）、`admins.json`、`settings.json`，以及 `backgrounds/` 目录（背景图）。需要备份时请一并复制，位于 AstrBot 提供的插件数据目录（通常为 `data/plugin_data/astrbot_plugin_scpsl_a2s/`；若当前版本不支持，则回退到插件目录下的 `data/`）。停机或空闲时复制这两个文件即可。JSON 损坏时插件会报错并拒绝写入，不会清空旧数据。

## 3.3升级提示
旧版 `servers.json`（全局服务器列表）与新版格式不同，新版不会读取旧的 `servers` 字段（文件里的旧字段会被保留，不会被删除）。升级后需要在各群重新 `/bind`。

## 3.4. 本地出图与背景图（v1.1.0）
- `/cx` 默认发送图片：每台服务器一张毛玻璃卡片（在线人数 / 上限、进度条、延迟；离线显示失败原因），底部汇总。
- 图片完全在本机用 Pillow 绘制。插件自带精简版思源黑体（Noto Sans CJK SC，OFL 协议，覆盖 GB2312 常用汉字）。若服务器名里有生僻字显示成方块，可把任意 `.ttf/.otf/.ttc` 字体放进数据目录的 `fonts/` 文件夹（优先级最高）。
- 背景图在 WebUI「背景与出图」里上传（PNG/JPG/WebP，≤15MB，最多 50 张，上传后会压缩重存）。
  - 点击某张图 = 指定为背景，再点一次取消；
  - 开启「随机背景」后每次 `/cx` 随机挑一张（此时指定背景不生效）；
  - 没有任何背景时使用内置深色渐变。
- 「/cx 以图片发送」开关关闭后恢复纯文字输出。
- 背景与设置保存在插件数据目录：`backgrounds/`、`settings.json`。

## 3.5. WebUI 管理页（v1.1.0）
入口：WebUI → 插件 → 点开本插件卡片 → 详情页里的「SCP:SL 查询管理」（部分版本会直接出现在左侧栏插件分组里）。页面访问受 Dashboard 登录保护。
- **服务器**：按群分组查看；添加 / 编辑 / 删除；「测试连接」会真实发起一次 A2S 查询。群标识写 `平台:群号`，只写群号默认 `aiocqhttp:`。
- **管理员**：添加 / 移除，不受“首位管理员”限制（可用来修复被抢先 `/op` 的情况）。
- **背景与出图**：上传 / 删除 / 指定背景、随机背景开关、出图开关、效果预览（用示例数据渲染，不会发到群里）。
- 删除类按钮需要点两次（第一次变成“确认？”），因为插件页运行在受限 iframe 里，浏览器的 confirm 弹窗不可用。
