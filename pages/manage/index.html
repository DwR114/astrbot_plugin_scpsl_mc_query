从 scplist.kr 找服务器

输入名称关键词（例如 沈阳）搜索在线服务器，点「填入」会把 ID 填到下面的表单。A2S 在你的服务器上连不通时，用 scplist ID 最稳。

    添加 / 更新服务器

    服务器按群隔离。群标识写 平台:群号，只写群号时默认 aiocqhttp:。同群同名再次保存会更新 IP 和端口。

    管理员
